# Nilanchala Mahanty Portfolio

Responsive personal portfolio built with HTML, CSS and JavaScript.

## Customize before publishing
1. Replace `assets/resume.pdf` with your actual resume PDF.
2. Replace `your.email@example.com` with your email.
3. Replace the GitHub and LinkedIn placeholder links with your profiles.
4. Replace `#` project links with your actual repositories.
5. Add a profile photo to `assets/` if desired.
6. Open `index.html` in a browser to preview.

## Publish
You can host this static website on GitHub Pages, Netlify or Vercel.
